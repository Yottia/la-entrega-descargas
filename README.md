## Bajar la última versión

👉 **[Descargar La Entrega para Android (APK)](https://github.com/Yottia/la-entrega-descargas/releases/latest/download/LaEntrega.apk)**

Este enlace siempre da la versión más nueva.

## Cómo instalarlo

1. Tocá el enlace de arriba desde el celular y esperá que se baje (pesa unos 220 MB, mejor con wifi).
2. Abrí el archivo `LaEntrega.apk` (en la notificación de la descarga o en la carpeta *Descargas*).
3. Si Android pregunta, permití **instalar apps de esta fuente** (el navegador o *Archivos*) y volvé atrás.
4. Tocá **Instalar** y después **Abrir**.

Para actualizar, bajá la versión nueva con el mismo enlace e instalala encima: se conserva tu partida.
